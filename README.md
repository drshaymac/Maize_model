# Simple Maize Model

In this exercise, we will be implementing a simple maize model as presented in Wallach et al. (2014), *Working with Dynamic Crop Models*. Tables and figures presented in this document are from the Wallach et al. text.  

Fork this repo to your personal NCSU Enterprise account, then clone the repo to your local computer by creating a new RStudio Project.  

This repo includes the following files:
- `maize_model_template.R`: A maize model script template. Replace the asterisks with code to implement the maize model.
- `maize_model_initial_implementation.html`: A description of the maize model code and how it should be implemented.  
- `maize_model_homework.html`: A description of the maize model homework, which includes creating a user-defined function with the maize model, calculating goodness-of-fit metrics, and applying the model to estimate maize yields in Robeson County, NC.  
- `data/`: A sub-directory including data files for the initial model implementation (data provided by Wallach et al. for a location in Europe), and for the Robeson County application.
